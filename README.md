# 深圳/浙江税务 一键填表登录（代账版 v16）

电子税务局 tpass 登录页的填表助手：搜到公司 → 点一下，自动填好「纳税人识别号 / 手机号 / 密码」并帮你点登录。

面向手上管着上百家公司的代账公司：支持公司名 / 拼音简拼 / 客户编号 / 税号后 4 位搜索、双击快捷键、在线授权、名单一键备份还原。

> 验证码（文字点选）**仍然要自己点**，脚本不做识别。原因见文末。



---

## 装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，把 `etax_login.js` 全文粘进去，保存
3. 打开深圳或浙江的 **tpass 登录页**，会自动弹出「添加公司」窗口

> 脚本只在 tpass 登录页生效。登录成功后跳到 etax.* 内网页面就不再注入任何东西，不干扰后续操作。

## 第一次用：填公司

弹窗五个字段：

| 字段 | 说明 |
| --- | --- |
| 公司全称 / 简称 | 建议填全称；面板会自动去行政前缀与法律后缀显示短名 |
| 归属城市 | 深圳 / 浙江 |
| 显示简称（选填） | 手工覆盖短名，用于多音字或系统自动生成得不好认时 |
| 客户编号（选填） | 如 `A001`，之后输编号就能直接找到这家 |
| 纳税人识别号 | 18 位统一社会信用代码 |
| 手机号 | 登录用的手机号 |
| 密码 | 登录密码，可勾「显示」核对有没有打错 |

三个按钮：

- **继续添加** — 存好当前这条，清空表单接着填下一家（城市会保留上次的选择）
- **取消** — 丢弃当前这条，关掉窗口
- **确定** — 存好当前这条，关掉窗口

录完一家点「继续添加」，录完最后一家点「确定」。中途取消也没关系，面板底部还有「➕ 添加」。

### 公司多的话：批量导入 / 导入模板

面板底部「📥 导入」打开后，点「复制导入模板」会填入一段可直接改的示例 JSON，这就是**预留给外部格式化脚本的标准模板**：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 公司全称，面板显示短名由脚本自动算 |
| `site` | 是 | `shenzhen` / `深圳` / `zhejiang` / `浙江` |
| `taxId` / `phone` / `password` | 是 | 原样填入登录表单 |
| `alias` | 否 | 手工覆盖展示短名（多音字兜底） |
| `code` | 否 | 客户编号，最快速的检索键 |
| `tags` | 否 | 附加检索词，如括号里的地名 |

也支持**每行一条、Tab 分隔、不带表头**，列序固定：`name  taxId  phone  password  site  alias  code`（后三列可省）。

点「导入（同名覆盖）」会先做一次汇总检查：未知站点、字段缺失、同名或去噪后显示名撞车，都会列在同一个弹窗里让你确认，不再逐条弹窗、也不再静默把未知站点当成深圳。同名覆盖，其余追加。**导入前自动存快照**，误导入可打开 Tampermonkey 脚本菜单点「🕘 恢复上一版名单」回退。

> 命名规则：数据层保留全称，展示层去掉「深圳市 / 广州市…」等行政前缀与「有限公司 / 分公司」等法律后缀（保留「科技 / 贸易」等行业词），括号内容抽成检索标签。于是「深圳市华兴科技」和「华兴（深圳）贸易」都能用 `华兴` / `hx` 找到。零依赖用 `Intl.Collator('zh-CN')` 生成拼音简拼，不加载任何外部字典。

## 日常用

1. 打开 tpass 登录页
2. **双击 `p`** 打开/关闭面板，**双击 `s`** 直接定位到搜索框（不区分大小写、不用组合键）
3. 输入公司名 / 简拼（如 `hxkj`）/ 客户编号 / 税号后 4 位；`↑↓` 选择、`Enter` 登录、`Esc` 关闭
4. 点公司名 → 自动切到「代理业务」→ 三字段自动填好 → 自动点登录
5. **手动点选验证码** → 登录完成

### 代理业务（代账版）

深圳 tpass 登录页顶部有「企业业务 / 自然人业务 / 代理业务」三个 Vue 标签。点公司名后脚本会先切到**代理业务**，等页面把表单整个重绘完，再填三字段并提交；已在代理业务则不重复点，跨站跳转回来也会照做。切换实测约 100ms。

- 浙江站若没有这个标签，脚本会跳过切换、照常填表（不报错、不阻塞）
- 4 秒内没切成功会**取消填表并红色提示**，绝不把数据填进「企业业务」表单提交
- 不想自动切换：Tampermonkey 图标 → 脚本菜单「🔀 代理业务自动切换：开 / 关」，设置会记住

焦点在输入框内时双击 `p`/`s` 不会误开面板（右上角按钮会轻闪一下提示先点空白处），这是为了避免在税号框里打出 `pp`/`ss`。

面板是贴页面右边缘的窄命令面板（最宽 300px）：打开时自动测量登录表单右缘并收窄，**不遮挡输入框与「登录」按钮**；点面板外任意处自动收起，把位置还给页面。顶部搜索框 + 站点筛选；结果先渲染 30 家，点「显示更多」继续加载；没有搜索词且超过 40 家时才出现 A–Z 分组与右侧字母条。

每行只显示公司短名，左侧 3px 细色条区分深圳（蓝）/ 浙江（绿）；**全称、站点、完整税号、手机尾号都放进鼠标悬停提示**，不再占行内宽度。未激活的公司灰显并带 🔒，删除按钮悬停才出现。小屏（<600px）自动变成底部抽屉。

在深圳站选浙江的公司，脚本会先跳到浙江站，跳过去接着自动填，不用再点一次。另外几个入口：

- 右上角「📋 一键填表」单击也能开/关面板（面板打开时会自动隐藏，不再两层重叠）
- Tampermonkey 图标 → 脚本菜单：搜索公司 / 添加 / 批量导入 / 备份 / 还原 / 🕘 恢复上一版名单
- 面板底部操作区（一行四个）：➕ 添加、📥 导入、⬇ 备份、⬆ 还原
- 「恢复上一版名单」已从面板移到脚本菜单：它是误导入/误删后的低频回退功能，不必常驻占空间；自动快照机制不变

## 授权（v16 起）

### 怎么激活（完整流程）

面板底部状态行右侧有一个**任何状态下都在**的入口：试用期是「输入授权码」，未激活 / 已过期是「激活 / 续期」，已激活是「授权信息 / 续期」。点开后：

1. **看设备码**（如 `f4uxxr8`），点「复制」发给客服 —— 换机、自助转移会用到；同时显示当前授权与到期日
2. 到 [专属落地页](https://etax.zhuyongfu.cn/login) 向客服购买 **`ETL-XXXX-XXXX`** 在线授权码（输入区里有直达链接）
3. 粘进输入框 —— **直接整段复制客服的聊天消息也行**，脚本会自动提取其中的授权码；按 `Enter` 或点「确认激活」
4. 提交时按钮变「校验中…」；成功显示到期日并自动解锁全部公司；失败**原样保留已输入内容**，并写明原因（码不存在 / 抄错漏字符 / 已过期 / 绑在别的设备 / 连不上授权服务器）
5. 再点「收起 ✕」即可关掉输入区，公司列表不会被挤矮

- 面板底部显示状态（未激活 / 试用 剩 N 天 / 已激活 N 天）
- 与「深圳税务助手」共用 `https://etax.zhuyongfu.cn` 的 `/v1/activate`、`/v1/refresh`，靠 `ETL-` 号段区分产品；不实现离线码
- 装好自动 **3 天全功能试用**；试用结束或过期后，**仅名单最前 3 家可自动填表，其余按钮灰显并带 🔒**（按名单原始顺序判断，搜索不能绕过；悬停可看原因）
- 授权凭证由服务器签发、脚本本地验签（ECDSA P-256）；续期后台改完，脚本最多 6 小时内自动拉到，无需操作
- 断网时已激活用户继续用本地凭证到到期，不会锁死；未激活用户仍可用前 3 家
- **未授权时名单一律可导出、可备份、可还原**，不会因为付费状态丢数据

## 备份与还原

- 「⬇ 备份」直接下载 `etax-名单-YYYY-MM-DD.json`（明文，含密码，请自己保管好）
- 「⬆ 还原」选文件 → 先弹差异预览（新增 X / 覆盖 Y / 跳过 Z）→ 选「合并」或「覆盖」，绝不静默覆盖
- 每次写库前自动留一份快照，最多 5 份；从 **Tampermonkey 脚本菜单 →「🕘 恢复上一版名单」** 可反复回退

## 数据存在哪

- 公司名单：Tampermonkey 的 `GM_setValue`，键名 `etax_accounts_v1`；快照 `etax_accounts_snapshots_v1`
- 授权记录：页面 `localStorage`，键名 `sz_login_license_v1`（与导出助手的 `sz_license_v1` 隔离）；设备号 `sz_dev_id` 与导出助手共用
- **更新脚本不会丢**，只有卸载脚本或清浏览器数据才会清掉
- 明文存在本机浏览器，不进源码、不上传任何服务器；联网仅用于校验授权状态
- 所以：只在自己的电脑上配，别用公共电脑

脚本代码里 `CONFIG.accounts` 是空数组，真实账号一条都没写进去 —— 这份代码可以直接公开，不用担心泄露。

## 常见问题

**为什么不做验证码自动识别？**  
试过。本地 ddddocr + 旋转模板匹配，实测成功率约 9%，等于不能用。真要全自动得接多模态大模型或打码平台，成本不划算。脚本只帮你省掉打三遍字段的功夫。

**换电脑 / 重装浏览器怎么办？**  
先在旧机器点「⬇ 备份」存一份 JSON，新机器装好脚本点「⬆ 还原」选文件即可，不用重新录。授权码绑设备，换机按落地页流程自助转移（每月 1 次）；重装脚本 / 清缓存后重新粘一次同一个授权码即可。

**为什么有些公司按钮是灰的？**  
试用结束或授权到期后只开放名单最前 3 家。点状态行右侧的「激活 / 续期」粘贴授权码即可全部解锁。

**填完没反应？**  
登录页是 Vue 动态渲染的，脚本会等表单出现（最多 15 秒）才注入按钮。如果一直不出现，多半是页面改版导致选择器失效，见下面的选择器表，改一下就行。

**点了公司名跳到别的站，但没自动填？**  
跨站靠本地存储传一次性的待填标记，2 分钟内有效。超时了就手动再点一次公司名。

## 技术细节

**生效范围**

```
https://tpass.shenzhen.chinatax.gov.cn:8443/*
https://tpass.zhejiang.chinatax.gov.cn:8443/*
```

**表单选择器**（页面是 Element UI）

| 字段     | 选择器                                 |
| ------ | ----------------------------------- |
| 纳税人识别号 | `.el-autocomplete .el-input__inner` |
| 手机号    | `.mobileInp > .el-input__inner`     |
| 密码     | `.pwdInp > .el-input__inner`        |
| 登录按钮   | `.el-col > .el-button`              |

> 注意 `.mobileInp > .el-input__inner` 是**直接子元素**。如果哪天页面在这中间多套一层 div，填表会静默失败（表现为点了没反应），改选择器即可。

**跨站跳转怎么传的**  
不走 URL 参数——那样公司名会留在地址栏和浏览器历史里。改用 `GM_setValue` 写一个 2 分钟有效的待填标记，目标页读完立刻删。只有本地存储写不进去时才退回 URL 参数兜底，且读完后会立刻擦掉地址栏。

## 归档：验证码自动识别为什么放弃

试过本地 ddddocr + 旋转模板匹配，**实测成功率约 9%（1/11、1/10）**，判定不可用：

- 验证码固定 4 个字，提示条与大图是同一字形，差异是旋转 + 删除线
- ddddocr 的 det 检测字位置较可靠但偶发漏检；连通域兜底会引入背景假框
- CCOEFF / IoU 两种匹配的 top1-top2 区分度只有 0.005~0.07，远低于可靠阈值
- 「少笔画字 ⊂ 多笔画字」会让 CCOEFF 虚高，换 IoU 也没改善

想要真·全自动，只能换多模态大模型识图或第三方打码平台。
